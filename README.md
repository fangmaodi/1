# Python 学习笔记

记录学习 Python 过程中的练习和总结。

## 定时任务练习

用 GitHub Actions 做了一个定时任务的练习，每 15 分钟运行一次，主要练了这几个东西：

- `requests`：发网络请求，拿网页上的数据
- 文件读写：读、写本地 txt 文件
- `subprocess`：调用外部命令行工具
- 定时触发：cron 表达式的写法

## 练习内容

`fofa_fetch.py` 分三步：

1. **收集数据**：去一个公开的数据源抓一些地址，用一个免费的查询接口查每个地址的归属地（省份、运营商），按归属地分文件写进 `ip/`。
2. **组合数据**（每 10 次运行一次）：把 `ip/` 里的地址和 `rtp/` 里的基础数据拼起来，生成一份组合后的清单，写进 `zubo.txt`。
3. **筛选验证**（每 10 次运行一次）：用外部工具测每个地址能不能用，能用的才留下来，按分类整理，生成 `IPTV.txt`。同时把可用的地址写回 `ip/`。

`.github/workflows/ip.yml` 是定时任务的配置文件：每 15 分钟跑一次，装 Python + requests + ffmpeg，运行脚本，然后自动提交改动并推送。

## 文件说明

- `fofa_fetch.py`：练习的主脚本
- `.github/workflows/ip.yml`：定时任务配置
- `rtp/`：练习用的基础数据
- `ip/`：收集到的地址列表（按归属地分文件）
- `计数.txt`：运行次数计数，每 10 次才做一次组合+筛选（省时间）
- `IPTV_example.txt`：输出文件的样子

## 运行方式

推送到仓库后，Actions 会自动按定时运行，也可以手动触发一次。

## 笔记

- 脚本里有个小问题：有个地方用了 `socket.gethostbyname` 但没 `import socket`，平时不影响，想修的话在文件开头加一行 `import socket` 就行。
- 数据源有访问频率限制，如果某次抓不到数据，等下一次跑就行。
- 每次只测一个代表地址，能用的就认为整组能用。
